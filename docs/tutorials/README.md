# Tutorials

Learning-oriented walkthroughs.

Planned for v1 (plan 11):

- **Quickstart: k3s + Tailscale + AWS** — run a k3s server on your laptop,
  join it to a tailnet, install SCarpenter with an AWS credential, create an
  `SCNodeClass` and a NodePool, schedule a Pod with an exact instance type and
  watch a Flatcar VM boot, join and go away again.
- **Local quickstart without a cloud account** — the same flow against the
  `qemu` development driver (Flatcar VMs on your machine).
