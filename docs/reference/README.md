# Reference

Technical descriptions of how specific parts of SCarpenter work.

Available:

- [**`SCNodeClass` API**](api.md) — every field, generated from the CRD
  (plan 02; regenerated by every plan that changes the API).
- [**Controller**](controller.md) — flags and environment variables, the Helm
  values, status conditions, the CloudProvider, metrics, Events and permissions
  (plan 02; extended by plans 03 to 09).
- [**Labels and annotations**](labels.md) — the names SCarpenter owns (plan 02).
- [**Labels and offerings**](labels-and-offerings.md) — instance-type naming,
  the values and Keeper sources of every label, how metrics and selection
  profiles are evaluated, refresh and staleness, the unavailable-offerings
  cache (plan 03).

- [**Driver contract**](driver-contract.md) — the `Driver` interface,
  capabilities, error classes, the conformance suite and the fake driver
  (plan 04). Quota-aware placement is in the [controller reference](controller.md#quota).

- [**Node bootstrap**](node-bootstrap.md) — the rendered Ignition, the Butane
  templates and their variables, bootstrap tokens, artifacts, the size budget,
  the NodeClass controller, the serving certificate approver, RBAC and security
  notes (plan 05).

- [**Node settings**](node-settings.md) — built-in defaults, vendor overrides,
  profiles, how a node's settings are resolved, the labels workloads select by,
  pricing, drift, the first-boot volume unit, kubelet reservations (plan 06).
- [**Vendor resources**](vendor-resources.md) — resource kinds, `use` / `create`
  / `forbid`, lifecycles, timing, status, garbage collection, metrics (plan 06).
- [**Resource selectors**](resource-selectors.md) — the one `use` selector for every
  kind on every vendor (`ids`, `name`, `tags`, `match`, native `filters`, `expression`,
  `select`, `orderBy`), its semantics and placeholders, and per vendor and kind what
  the API filters server-side and what the client does (plan 14).

- [**AWS driver**](aws-driver.md) — regions, zones, images, launch, node settings,
  resources and network, tags, quota classes and codes, error mapping, IAM
  ([policy](aws-iam-policy.json)) and what is not verified live yet (plan 08).

- [**Azure driver**](azure-driver.md) — regions and zones, marketplace images, launch,
  node settings, managed resources, quota, errors, the role ([actions](azure-role.json)) and what is not
  verified live yet (plan 17).
- [**Hetzner Cloud driver**](hcloud-driver.md) — the `hcloud` driver: regions, images and the label convention,
  launch, node settings, resources, quotas, billing, error mapping and what is not verified live yet (plan 15).
- [**Vultr driver**](vultr-driver.md) — the Vultr Cloud Compute driver: snapshots as images, firewall groups and VPCs, the plan list, error mapping and what is not verified live yet (plan 20).
- [**GCP driver**](gcp-driver.md) — the Google Compute Engine driver, lower layers (plan 16).
- [**UpCloud driver**](upcloud-driver.md) — regions that are zones, the Flatcar template
  convention, the two firewalls, launch, node settings, resources, quotas, errors, credentials
  and what is not verified live yet (plan 19).
- [**Alibaba Cloud driver**](alicloud-driver.md) — regions, zones, images (your own, rung 3), launch, node settings, resources and network, the metadata service, quotas, billing, RAM ([policy](alicloud-ram-policy.json)) and what is not verified live yet (plan 21).
- [**OVHcloud driver**](ovh-driver.md) — the OVHcloud Public Cloud driver: regions and zones,
  images, launch, node settings, resources, quotas, error mapping, rights
  ([policy](ovh-iam-policy.json)) and what is not verified live yet (plan 18).

- [**Infrastructure hand-off**](infrastructure-handoff.md) — the IaC-neutral
  contract: what you provide per vendor, by the [selector](resource-selectors.md) (resource
  kinds and `use` forms, account scope and credentials, Flatcar images), what
  SCarpenter does without it, the published CRD, [JSON Schema](schema/scnodeclass.schema.json) and
  [examples](../examples), and what the controller's identity needs per vendor (plan 14).
